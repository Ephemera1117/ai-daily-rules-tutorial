## 🎯 核心思路

这套方案的本质是**分类注入**：

1. **规则常驻可见** → AI 每次对话都能看到规则
2. **状态动态记录** → 通过备忘录记录最近的执行情况
3. **时间感知** → 让 AI 知道时间流逝
4. **主动提醒** → 通过提示词提醒 AI 使用工具、记录状态、调整规则

即使不做任何二改，通过现有软件的工作区、记忆、模式注入等功能组合，也能实现类似效果。

## ⚠️ 局限说明

1. **依赖自觉性**：规则执行和汇报比较依赖你的自觉，不发消息时管不到
2. **平台限制**：主要针对 Android（RikkaHub），iOS 用户可能需要适配
3. **Token 成本**：多种注入会增加 token 消耗（笔者实际使用消耗不多）
4. **模型特性依赖**：笔者使用 Claude Opus 4-6，其他模型需要自己适配
